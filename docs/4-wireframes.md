# 색연필 색소폰 동호회 홈페이지 - 와이어프레임

## 0. 문서 개요
본 문서는 도메인 정의서(`1-domain-definition.md`, v0.6), PRD(`2-PRD.md`, v0.7), 사용자 시나리오(`3-user-scenario.md`, v0.7)를 기반으로 주요 화면의 레이아웃을 ASCII 박스 다이어그램으로 정리한다. 실제 디자인 시스템/색상/타이포그래피는 다루지 않으며, 화면 구성요소와 관련 기능ID 확인용 참고 자료로 사용한다.

각 화면의 SVG 도면은 `docs/wireframes/` 하위에 화면 번호와 동일한 파일명으로 보관한다(예: 2번 홈 화면 → `02-home.svg`, 모바일 버전은 `-mobile` 접미사, 공통 네비게이션은 `00-nav-mobile.svg`). 본 문서의 ASCII 다이어그램과 SVG 파일은 항상 동일한 내용을 유지한다.

## 1. 공통 사항
- 상단 공통 네비게이션(로고, 게시판, 연습실 예약, 마이페이지, 로그인/로그아웃, [관리자] 메뉴 - 관리자 등급에만 노출)을 모든 화면에서 공유한다.
- **반응형 규칙(요약)**:
  - 폼 위주 화면(회원가입/로그인/마이페이지/예약 신청 등)은 PC/모바일 모두 1열 레이아웃이라 폭만 좁아질 뿐 구성은 동일하다. 별도 모바일 와이어프레임은 생략한다.
  - 표(테이블) 위주 화면(게시글 목록, 연습실 예약현황, 내 예약 내역 등)은 모바일에서 표를 그대로 축소하지 않고 **행 단위 카드 리스트**로 전환한다. 아래 각 화면에 모바일 버전을 별도로 표기한다.
  - 상단 네비게이션은 모바일에서 햄버거(≡) 아이콘 안으로 축소된다.
  - 관리자 화면은 회원 수(500명 이하) 규모상 주로 PC에서 운영된다고 가정하고, 모바일에서는 표를 가로 스크롤로 그대로 보여주는 것으로 충분하다(별도 모바일 와이어프레임 생략).

### 공통 네비게이션 - 모바일(햄버거 메뉴)
```
+----------------------+
| 색연필           [≡] |
+----------------------+
        (탭 시 펼쳐짐)
+----------------------+
| 게시판                |
| 연습실예약             |
| 마이페이지             |
| 관리자 (관리자만 노출) |
| 로그아웃               |
+----------------------+
```

## 2. 홈 화면 (첫 화면)

```
+--------------------------------------------------+
| 색연필   게시판 | 연습실예약 | 마이페이지 | 로그인 |
+--------------------------------------------------+
|                                                    |
|              색소폰 동호회 "색연필"에 오신 것을     |
|              환영합니다                            |
|                                                    |
|   [ 게시판 바로가기 ]     [ 연습실 예약 바로가기 ]  |
|                                                    |
+--------------------------------------------------+
```
- 핵심 요소: PC 접속 시 첫 화면은 상단 메뉴바(게시판/연습실예약/마이페이지/로그인 또는 로그아웃, 관리자 등급이면 [관리자] 메뉴 추가 노출)를 통해 전체 메뉴를 바로 보여준다. 별도의 슬라이드 배너 등 홈페이지 전용 콘텐츠는 두지 않고, 환영 문구와 주요 기능(게시판/연습실예약) 바로가기만 배치한다.
- 비로그인 상태에서는 메뉴바에 "로그인"이 노출되고, 로그인 상태에서는 "로그아웃"으로 바뀐다.
- 모바일에서는 1번 항목의 공통 규칙대로 메뉴바가 햄버거(≡) 메뉴로 축소되고, 환영 문구/바로가기 버튼은 1열로 쌓인다(별도 모바일 와이어프레임 생략).
- 관련 기능: F-02(로그인 상태 표시), F-10(게시판 바로가기), F-20(연습실예약 바로가기)

## 9. 연습실 목록/예약현황 조회 화면 (S-05, F-20)

```
+--------------------------------------------------+
| 색연필   게시판 | [연습실예약] | 마이페이지 | 로그아웃 |
+--------------------------------------------------+
|  연습실 선택: [ 1연습실 ▾ ]   날짜: [ 2026-09-09 ▾]|
+--------------------------------------------------+
|  하루 전체 예약현황 (30분 단위, 운영시간 09:00-22:00)|
|  [ ] 09:00-09:30    예약가능                       |
|  [ ] 09:30-10:00    예약가능                       |
|  [ ] 10:00-10:30    예약가능                       |
|  [x] 10:30-11:00    예약불가 (김OO)                |
|  [ ] 11:00-11:30    예약가능                       |
|  ...                (스크롤로 나머지 시간대 확인)   |
+--------------------------------------------------+
|  선택한 시간대: 09:00 ~ 10:30 (30분 단위 3슬롯)     |
|                              [ 예약 신청 ]          |
+--------------------------------------------------+
|  내 예약 내역 보기 >                                |
+--------------------------------------------------+
```
### 모바일(카드 리스트)
```
+----------------------+
| ≡ 연습실예약          |
+----------------------+
| 연습실 [1연습실 ▾]    |
| 날짜   [09-09 ▾]      |
+----------------------+
| [ ] 09:00-09:30 가능  |
| [ ] 09:30-10:00 가능  |
| [ ] 10:00-10:30 가능  |
| [x] 10:30-11:00 불가  |
| ...    (스크롤)       |
+----------------------+
| 선택: 09:00~10:30(3) |
|        [ 예약 신청 ] |
+----------------------+
| 내 예약 내역 보기 >    |
+----------------------+
```

- 핵심 요소: 연습실/날짜 선택 시 하루 전체(운영시간) 예약현황을 30분 단위 시간대 목록으로 표시. 빈 슬롯은 체크박스로 다중 선택 가능하며, **연속된 슬롯만** 하나의 예약으로 선택할 수 있다(비연속 선택 시 안내 후 재선택 유도). 선택 결과(시작~종료, 슬롯 수)를 하단에 요약하고 예약 신청 버튼으로 다음 화면(10번)으로 이동.
- 모바일: 시간대별 표를 체크박스가 있는 카드로 전환하고, 선택 요약+예약 신청 버튼을 화면 하단에 배치.
- 관련 기능: F-20

```
+----------------------+
| ≡ 내 예약 내역        |
+----------------------+
| 연습실 [ 전체 ▾ ]     |
+----------------------+
| 1연습실 · 09-09        |
| 09:00-10:00 · 예약     |
|              [ 취소 ] |
+----------------------+
| 2연습실 · 09-08        |
| 18:00-19:00 · 완료     |
+----------------------+
| 1연습실 · 09-07        |
| 20:00-21:00 · 취소     |
+----------------------+
```

- 핵심 요소: 상단 연습실 필터(드롭다운, 기본값 "전체")로 선택한 연습실의 예약만 목록에 표시. 예약상태(예약/완료/취소)별 표시, "예약" 상태이면서 시작 전인 건에만 취소 버튼 노출. 시작 후 취소 시도는 서버에서 거부.
- 모바일: 예약 1건당 1개 카드(연습실/날짜/시간대/상태+취소 버튼)로 표시, 필터는 카드 목록 위 드롭다운으로 배치.
- 관련 기능: F-22
