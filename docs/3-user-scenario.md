## 1. 일반 회원 시나리오

### S-01. 신규 회원가입 및 로그인 (F-01, F-02)
- **사용자**: 신규 회원 (직장인)
- **사전조건**: 아직 회원가입하지 않은 상태
- **진행 흐름**
  1. 퇴근 후 저녁, 스마트폰 브라우저로 홈페이지에 접속한다.
  2. 회원가입 화면에서 이름/이메일(로그인ID)/비밀번호/연락처를 입력하고 가입을 완료한다.
  3. 시스템은 신규 회원에게 기본 등급(예: 준회원)을 부여한다.
  4. 이메일/비밀번호로 로그인한다.
  5. 서버는 Access Token(단기)과 Refresh Token(장기)을 발급한다.
  6. 이후 Access Token이 만료되면 클라이언트는 Refresh Token으로 재발급을 요청해 로그인 상태를 유지한다.
- **결과/예외**
  - 이메일 중복 가입 시 가입 실패 안내.
  - 비밀번호 불일치 시 로그인 실패 안내.
  - Refresh Token도 만료/폐기된 경우 재로그인 필요.

### S-02. 본인 정보 수정 (F-03)
- **사용자**: 로그인 회원
- **사전조건**: 로그인 완료
- **진행 흐름**
  1. 마이페이지(내 정보) 화면에 진입한다.
  2. 연락처 등 본인 정보를 수정 후 저장한다.
  3. 시스템은 변경된 정보를 반영한다.
- **결과/예외**
  - 이메일(로그인ID) 등 변경이 허용되지 않는 항목은 수정할 수 없다.
  - 필수 항목 누락/형식 오류 시 저장이 거부되고 안내 메시지가 표시된다.

### S-03. 등급에 따른 게시판 접근 제한 (F-10, F-11)
- **사용자**: 준회원 (기본 등급)
- **사전조건**: 로그인 완료, 특정 게시판("운영진 전용" 등)의 이용가능 최소등급이 "정회원" 이상으로 설정됨
- **진행 흐름**
  1. 게시판 목록에서 자신의 등급으로 접근 가능한 게시판만 노출되거나, 목록은 보이되 진입 시 제한된다.
  2. 준회원이 최소등급 미달 게시판에 진입을 시도한다.
  3. 시스템은 회원 등급과 게시판 최소등급을 비교해 접근을 거부한다.
- **결과/예외**
  - 접근 거부 시 "이용 권한이 없는 게시판" 안내 메시지 표시.
  - 이후 관리자가 등급을 상향(S-07)하면 재로그인/재조회 시 접근 가능해진다.

### S-04. 게시글 작성 및 본인 글 수정/삭제 (F-11, F-12)
- **사용자**: 정회원 (해당 게시판 접근 가능 등급)
- **사전조건**: 접근 가능한 게시판에 로그인 상태로 진입
- **진행 흐름**
  1. 게시판에서 글쓰기를 선택해 제목/내용을 작성 후 등록한다.
  2. 목록에서 본인 글의 조회수가 증가함을 확인한다.
  3. 본인이 작성한 글에서 수정 버튼으로 내용을 변경한다.
  4. 필요 시 삭제 버튼으로 글을 삭제한다.
- **결과/예외**
  - 타인이 작성한 글에는 수정/삭제 버튼이 노출되지 않거나 시도 시 거부된다(본인 또는 관리자만 가능, F-12).
  - 등급 조건 미충족 상태에서 작성 API를 직접 호출해도 서버에서 거부된다.

### S-05. 연습실 예약현황 조회 및 신청, 중복예약 거부 (F-20, F-21)
- **사용자**: 로그인 회원
- **사전조건**: 예약하려는 연습실이 사용 중(활성) 상태
- **진행 흐름**
  1. 연습실 목록에서 원하는 연습실과 날짜를 선택하면, 해당 하루(운영시간) 전체의 예약현황이 30분 단위 시간대로 표시된다.
  2. 비어 있는 30분 단위 시간대 중 연속된 여러 슬롯(예: 09:00~10:30, 3개 슬롯)을 선택해 하나의 예약으로 신청한다.
  3. 시스템은 선택 구간에 포함된 모든 슬롯에 기존 예약이 없는지 확인 후 예약을 확정한다.
  4. 다른 회원(또는 동일 회원)이 같은 연습실·겹치는 시간대(선택 구간 일부만 겹쳐도 포함)에 다시 예약을 시도한다.
  5. 시스템은 겹치는 슬롯이 있음을 확인하고 예약을 거부한다.
- **결과/예외**
  - 선택 구간 내 슬롯 중 하나라도 이미 예약되어 있으면 "이미 예약된 시간대가 포함되어 있습니다" 안내와 함께 신청 전체가 거부된다.
  - 운영시간 외 시간대는 애초에 선택 불가하도록 노출을 제한한다.

### S-06. 예약 취소 (시작 전 vs 시작 후) (F-22)
- **사용자**: 예약자 본인
- **사전조건**: 본인 명의의 예약이 존재
- **진행 흐름 (연습실별 필터링)**
  1. 내 예약 내역 화면에서 연습실 필터를 선택하면, 해당 연습실의 예약 건만 목록에 표시된다.
  2. 필터를 "전체"로 초기화하면 모든 연습실의 예약 내역이 다시 표시된다.
- **진행 흐름 (시작 전 취소 - 정상)**
  1. 예약 내역에서 아직 시작 시간이 되지 않은 예약을 선택한다.
  2. 취소 버튼을 눌러 예약을 취소한다.
  3. 시스템은 예약상태를 "취소"로 변경하고 해당 시간대를 다시 예약 가능하게 연다.
- **진행 흐름 (시작 후 취소 시도 - 거부)**
  1. 이미 시작 시간이 지난(또는 진행 중인) 예약을 선택한다.
  2. 취소 버튼을 누른다.
  3. 시스템은 현재 시각과 예약 시작 시간을 비교해 취소를 거부한다.
- **결과/예외**
  - 시작 후 취소 시도 시 "이미 시작된 예약은 취소할 수 없습니다" 안내.
  - 취소된 예약은 예약자 본인의 이력에는 남되(취소 상태), 시간대는 타 회원이 재예약 가능.

## 2. 관리자 시나리오

### S-07. 회원 등급 변경 (F-30)
- **사용자**: 관리자 (운영진 등급)
- **사전조건**: 관리자 메뉴 접근 권한 보유, 대상 회원이 존재
- **진행 흐름**
  1. 관리자 메뉴 > 회원 목록에서 등급을 변경할 회원을 검색/선택한다.
  2. 현재 등급(예: 준회원)을 확인하고 새 등급(예: 정회원)으로 변경한다.
  3. 저장 시 시스템은 해당 회원의 등급을 갱신한다.
- **결과/예외**
  - 변경 즉시(또는 대상 회원의 다음 로그인/토큰 갱신 시) 새 등급 기준의 게시판 접근 권한이 적용된다.
  - 관리자가 아닌 계정은 이 메뉴 자체에 접근할 수 없다.

### S-08. 게시판/연습실 관리 (생성/수정) (F-31, F-32)
- **사용자**: 관리자
- **사전조건**: 관리자 메뉴 접근 권한 보유
- **진행 흐름 (게시판 관리)**
  1. 관리자 메뉴 > 게시판 관리에서 신규 게시판을 생성하거나 기존 게시판을 선택한다.
  2. 게시판명, 설명, 이용가능 최소등급, 사용여부(활성/비활성)를 설정/수정한다.
  3. 저장하면 해당 설정이 즉시 게시판 목록/접근 제어(F-10)에 반영된다.
- **진행 흐름 (연습실 관리)**
  1. 관리자 메뉴 > 연습실 관리에서 신규 연습실을 등록하거나 기존 연습실을 선택한다.
  2. 연습실명, 위치, 수용인원, 운영시간, 사용여부를 설정/수정한다.
  3. 필요 시 예약 현황/내역을 조회하고, 특정 예약을 관리자 권한으로 취소한다.
- **결과/예외**
  - 사용여부를 "비활성"으로 변경한 게시판/연습실은 일반 회원에게 목록에서 숨겨지거나 신규 이용(글쓰기/예약)이 제한된다.
  - 관리자의 예약 취소는 시작 여부와 무관하게 허용된다(운영 목적, 도메인 정의서 4.2절 참고).
