## 1. 프로젝트 개요
색소폰 동호회 "색연필"의 회원관리, 커뮤니케이션(게시판), 연습실 예약을 지원하는 홈페이지를 개발한다. 인증된 회원만 이용 가능하며, 회원 등급에 따라 게시판 이용 범위가 달라진다.

**범위 제외**: 자료실 기능은 원 요구사항에 있었으나 본 버전 범위에서 제외한다(변경 이력 v0.2 참고).

## 2. 핵심 도메인(엔티티)

### 2.1 회원 (Member)
- 주요 속성: 회원ID, 이름, 이메일(로그인ID), 비밀번호, 연락처, 가입일, 회원등급, 계정상태(활성/휴면/탈퇴)
- 설명: 회원가입 후 로그인해야 서비스 이용 가능. 로그인 사용자는 자신의 정보 수정 가능.
- 계정상태 전이: 활성 → 일정 기간 미접속 시 휴면 → 본인 요청 또는 관리자 처리로 탈퇴. 탈퇴 회원은 로그인 불가.
- **구현 범위**: 세 값(`active`/`dormant`/`withdrawn`)은 스키마에 CHECK 제약으로 들어가 있고 **탈퇴(`withdrawn`) 차단만 구현**되어 있다 — 탈퇴 회원은 로그인·글쓰기·예약이 모두 거부된다. 반면 **휴면으로 전환하는 경로는 구현하지 않았다**: "일정 기간 미접속" 판정에는 마지막 접속 시각 컬럼과 이를 주기적으로 훑는 배치가 필요한데 둘 다 이번 범위에 없고, 회원가입 시 값은 항상 `active`이며 상태를 바꾸는 API도 두지 않았다. `dormant`인 회원은 현재 로그인이 통과한다(차단 대상이 아니다). 휴면 정책이 실제로 필요해지면 마지막 접속 시각과 전환 주체(배치 또는 관리자 조작)를 먼저 정해야 한다.

### 2.2 회원등급 (MemberGrade)
- 주요 속성: 등급ID, 등급명(예: 준회원/정회원/운영진 등), 설명, 권한범위
- 설명: 게시판 이용 제한의 기준이 되는 값. 관리자가 등급 체계와 회원별 등급을 관리.
- "관리자"는 별도의 액터가 아니라 회원등급 중 관리자 메뉴 접근 권한을 가진 최상위 등급(예: 운영진)을 의미한다.

### 2.3 게시판 (Board) / 게시글 (Post)
- 게시판 속성: 게시판ID, 게시판명, 설명, 이용가능 최소등급, 사용여부
- 게시글 속성: 게시글ID, 게시판ID, 작성자(회원ID), 제목, 내용, 작성일, 조회수
- 설명: 게시판별로 접근/작성 가능한 최소 회원등급을 설정할 수 있음.

### 2.4 연습실 (PracticeRoom)
- 주요 속성: 연습실ID, 연습실명, 위치, 수용인원, 운영시간, 사용여부
- 설명: 동호회가 운영하는 예약 대상 공간. 관리자가 등록/수정/삭제 관리.

### 2.5 예약 (Reservation)
- 주요 속성: 예약ID, 연습실ID, 예약자(회원ID), 예약일자, 시작시간, 종료시간, 예약상태(예약/완료/취소)
- 설명: 회원이 연습실 예약현황을 조회하고 예약/취소할 수 있음. 예약시간 경과 후 상태는 완료로 전환된다.
- **구현 범위**: `completed`는 스키마와 조회·표시 로직이 모두 다루지만, **경과한 예약을 `completed`로 바꾸는 전환은 구현하지 않았다** — 시각을 기준으로 상태를 옮기려면 주기 배치(또는 조회 시점의 일괄 UPDATE)가 필요하고 그것은 이번 범위에 없다. 따라서 시작 시각이 지난 예약도 값은 `reserved`로 남는다. 기능상 문제가 되지 않는 이유는 취소 가능 판정이 상태만 보지 않고 **`reserved`이면서 시작 시각 전**인지를 함께 보기 때문이다 — 경과한 예약은 상태가 `reserved`여도 취소 버튼이 노출되지 않고, 서버도 403으로 거부한다. 다만 화면의 상태 표시는 "예약"으로 보인다.
- 예약현황은 하루(운영시간 전체) 단위로 조회하며, 예약은 30분 단위로 신청한다. 비어있는 30분 단위 시간대를 연속으로 선택해 하나의 예약으로 묶어 신청할 수 있다(예: 09:00~10:30 = 3개 슬롯 연속 예약).

## 3. 도메인 간 관계
- 회원 : 회원등급 = N : 1 (회원은 하나의 등급을 가짐)
- 회원등급 : 게시판 = 1 : N (등급별 접근 가능한 게시판 제한)
- 회원 : 게시글 = 1 : N, 게시판 : 게시글 = 1 : N
- 회원 : 예약 = 1 : N, 연습실 : 예약 = 1 : N

## 4. 주요 기능 요약

### 4.1 일반 회원
- 회원가입, 로그인/로그아웃, 본인 정보 수정
- 등급에 따라 허용된 게시판 열람/글쓰기
- 연습실 예약현황 조회, 예약 신청/취소

### 4.2 관리자
- 회원 등급 관리(등급 생성/수정, 회원별 등급 부여). 구현 범위: 회원별 등급 부여와 등급 생성은 화면·API 모두 있고, **등급 수정은 API만 있고 화면은 만들지 않았다**(와이어프레임 12번 "구현 결과" 참고).
- 게시판 관리(생성/수정/삭제, 게시판별 이용 최소등급 설정)
- 연습실 관리(등록/수정/삭제, 예약 현황/내역 관리). 관리자는 예약 시작 여부와 무관하게 예약을 취소할 수 있다(운영 목적의 예외, §6 참고).

## 5. 등급별 기능 제한 개념
각 게시판은 "이용가능 최소등급"을 가지며, 로그인 회원의 등급이 이 기준 이상일 때만 열람/작성이 허용된다. 등급 기준은 관리자 메뉴에서 게시판 단위로 설정한다.

## 6. 주요 비즈니스 규칙
- 동일 연습실은 같은 시간대에 중복 예약될 수 없다.
- 예약 시간 단위는 30분이며, 연속된 30분 슬롯을 묶어 하나의 예약으로 신청할 수 있다. 연속 구간 내 슬롯 중 하나라도 이미 예약되어 있으면 전체 신청이 거부된다.
- 게시글은 작성자 본인 또는 관리자만 수정/삭제할 수 있다.
- 탈퇴한 회원의 게시글/예약 이력은 삭제하지 않고 보존하되, 해당 회원은 더 이상 로그인·예약·글쓰기를 할 수 없다.
- 예약 취소는 예약 시작 전에만 가능하다. 단, 관리자는 예약 시작 여부와 무관하게 예약을 취소할 수 있다.
